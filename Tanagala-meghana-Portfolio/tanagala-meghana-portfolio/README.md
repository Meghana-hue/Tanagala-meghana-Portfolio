# Tanagala Meghana — Portfolio

Personal portfolio website for **Tanagala Meghana**, a B.Tech Computer Science and Engineering (AI & ML) student at VIT-AP University.

The portfolio highlights projects, technical skills, education, certifications, leadership experience, and current areas of focus.

## Overview

This is a responsive static portfolio website built with HTML, CSS, and JavaScript.

Profile and portfolio content is maintained separately in `assets/js/profile.js`, while `assets/js/main.js` handles rendering the content on the page.

## Features

- Responsive personal portfolio website
- About and current focus sections
- Projects and technical skills
- Education and certifications
- Leadership experience
- Contact and professional profile links
- Profile photo
- GitHub Pages deployment support
